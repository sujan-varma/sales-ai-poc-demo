# Pitch — Today's Route & Calendar (standalone)

*Adds to the Pitch — Canvas Redesign prompt — doesn't replace it. Two new screens: Today's Route and Calendar, both reachable from Pitch's sidebar area alongside Generate and All Pitches.*

## Grounded in the blueprint — J1, before the day and route preparation

- **Before the day:** “Opens the queue on a handset. Sees today's actions ranked by agreed value and due date, with carried-forward items showing their age.”
- **Route preparation:** “Selects today's outlets. Inherits the pitch strategy the manager set for the month, picks the conversation language, generates and downloads... cached for offline use.”

Today's Route is this stage made into its own screen — not folded into a generic action list, because for a sales officer it's the single most load-bearing thing on the platform.

## Bondex context

- **Reference persona:** Ajay Talukar, sales officer under Raman, Saurashtra.

## Today's Route

A list, sourced from the beat/week planner (Pitch's third-tier source — it determines this list's content directly, even though it never appears as a talking point inside a pitch itself). One row per outlet scheduled for today:

- Outlet name, type, class, scheduled time
- **Pitch status:** either a green **Ready** state — opens the existing pitch (read view, per All Pitches' Detail-vs-Edit distinction) — or a **Generate** CTA that opens Pitch's canvas, pre-scoped to that outlet, scope type already set to Retailer or Distributor as appropriate

No separate confirmation step — clicking Ready or Generate goes straight to the relevant screen, same directness as every other entry point in Cortex.

## Calendar

A date picker; selecting any future date shows that date's planned route in the same list format as Today's Route — so an officer can pre-build pitches for tomorrow or next week, not just react to today.

## Pitch freshness — what's new since generation

A pitch isn't static once built. If something relevant arrives from any of Pitch's seven sources after generation — a new Huddle flag, a Thermometer recommendation, a Tracker escalation touching this outlet — the existing pitch has to surface it:

- Its row in Today's Route (and in All Pitches) shows a **“Needs update”** flag instead of a plain Ready state
- Opening it shows exactly what's new, in the same why/what/source-link shape as any other surfaced item
- The officer can accept the update into the pitch or dismiss it

**This is why a pitch needs edit history.** Every change — generated, updated with a new signal, manually edited — is a version, same pattern as Market Action Plan's plan versioning: an icon showing which version is current, older ones one click away.

## Worked example — Ajay

Ajay opens Today's Route: five outlets, three already Ready, two showing Generate. He taps Generate for the fourth, builds it in Studio's canvas, done in two minutes. That evening, a new Thermometer recommendation lands for one of his Ready outlets — by morning, that row reads Needs Update. He opens it, sees the new point with its evidence, accepts it — the pitch is now v2, and the edit history shows exactly what changed and when. Separately, he checks Calendar for Thursday — sees his route, starts building two of Thursday's pitches now while he has time.
